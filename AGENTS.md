## Agent skills

### Issue tracker

GitHub Issues in `Freedom0x0/jmb-agent` (private), via `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five state labels; category labels are `bug` / `enhancement`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/`. See `docs/agents/domain.md`.

### Change log

Every change (code, tests, docs) gets a brief one-line entry in `docs/changelog.md` — date + what changed. No essays; rationale lives in `docs/decisions.md`.
