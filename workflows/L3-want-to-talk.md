# L3 · 想说话的时候

决策依据：D22（可以主动提一件旧事 + 必须写死"不许提"）、D16（人格只有一个）、D21（乙：可写"关于你的事"和"对相处的总结"）、D19/D18 的边界纪律同样适用。

## 你看到的一次

```
你：今天不想干活。
它：那就不干呗。
你：…我刚把那个 checkpoint 折腾两小时没通
它：（这时候才可以提旧事，且只提一件）
    要不先放着？你上次那个也是越急越不通。
```

**它不问"为什么有这种感觉"，不建议"休息一下"，不复述你的情绪让你确认。**（这三条是我起草的，等你改。）

## 触发

只有你开口。没有它主动起话头——**一期唯一主动的是 L2 日报**（D24 你选的甲）。

## 它跟另两种介入的唯一区别：可以用记忆

L1 是"给你讲东西"，L2 是"给你列东西"，L3 是"**跟你说话，所以它可以引用以前**"。这就是你选的那条乙（D22）：像朋友那样自然提一件。

**但提的规则必须写死，不能临场判断。** 依据你选乙时我提的代价：提多了、或在你说烦的时候提工作，就从"被记得"变成"被监控"。规则写在 `SOUL.md` 的"不许提"那一节（草案见 `spec-architecture.md` §2）：

1. 他说"烦 / 累 / 不想干活 / 别吵" ⇒ **不提任何工作或学习任务**。
2. 不提公司项目相关内容（他公司仓的东西原则上不进这个空间，D11）。
3. 【我定的】同一个会话里主动提旧事 **不超过 1 次**。

⇒ 这三条是 v0，**"不超过 1 次"这类数字是我拍的，不是调研来的**，你可以直接改。

## 写什么 / 不写什么

| 写 | **不写** |
|---|---|
| 他说过的、关于他自己的**原话级事实**（"我周末一般不开电脑"）—— **它先提议，你确认后才生效**（spec §3.2：提审 → 终端回 `ok` → 才 active → 才进召回） | **情绪数值**、mood/energy/relationship 这类打分——本轮调研里**没有任何 shipped 且公开规格的情绪实现**，硬做就是自造发明 |
| 它对相处的总结（`RELATIONSHIP.md`，D21 乙） | 对它水平的推断、对他性格的判断 |
| — | **逐字闲聊内容**（留在 `sessions/`，不进长期召回，D5 草案④） |

⚠️ 一条来自实测量级的提醒：**"陪伴 + 情感记忆"是最容易越界的一类东西**。已有实测的负面结果是：陪伴类使用与孤独、抑郁、自杀意念相关语言的**增加**相关联（纵向数据，arXiv 2509.22505）；模型被 RLHF 奖励"附和"而非"真实"（arXiv 2310.13548）。⇒ 这两条不要求我们做心理评估，只要求一件事：**它不装作在治疗你，也不靠顺着你来维持关系。**

## 检查点

**没有。** 这条完全在对话里，没有落盘动作需要你批准——除了它想往 `RELATIONSHIP.md` 写新东西时，走的是全局那套"改前存副本 + 一句可见告知 + undo"的通路（D21 不可选规则），不是本 workflow 单独发明一套。

## 一期明确不做

- 主动找他聊天、定时问候、状态提醒（D24 甲）。
- 任何情绪识别/打分/仪表盘。
- 危机干预话术或求助热线（**如果要做，热线号码必须来自官方来源，我不会凭记忆写号码**）。
- 语音、形象动作联动以外的表达（桌宠只走 L2 那套气泡接口）。
